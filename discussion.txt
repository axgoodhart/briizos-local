⏺ Actual AI Loop Implementation

  Here's the complete execution flow, step by step:

  1. User Input → AI Response Flow

  User types in InteractionPanel
      ↓
  InteractionPanel.jsx: handleSubmit()
      ↓
  useChat.js: sendMessage(message)
      ↓
      - Adds user message to Firestore
      - Gets selected files, builds context addendum
      - Calls chatAPI.streamChat()
      ↓
  chat-api.js: streamChat()
      ↓
      - Injects system prompt with tool definitions
      - Makes HTTP request to AI provider (Gemini/Claude/OpenAI)
      - Streams response chunks
      - Parses chunks for tool calls (JSON blocks like
  ```json{"tool":"...","params":{}}```)
      ↓
  Back in useChat.js sendMessage():
      ↓
      For text chunks: accumulates in streamContentRef.current
      For tool_call chunks: calls executeToolCall(chunk)
      ↓
  executeToolCall()
      ↓
      - Creates tool call object with status 'running'
      - Calls briizToolsRef.current.execute(tool, params)
      ↓
  briizos-tools.js: execute()
      ↓
      - Looks up tool in registry (from tools.js)
      - Checks if requiresConfirmation → shows margerin if yes
      - Calls tool.handler(params, appContext, layoutHook)
      ↓
  tools.js: handler (e.g., createNotePanel, agentReadFile, etc.)
      ↓
      - Executes actual logic (Firestore calls, IPC calls, etc.)
      - Returns result
      ↓
  Result appended to stream content
      ↓
  Final assistant message saved to Firestore

  2. Tool Bridge (Python Agent Path) - Exists but Unused

  Python agent (if running)
      ↓
  HTTP POST to http://127.0.0.1:2025/tools/{toolName}
      ↓
  electron/tool-bridge.js: HTTP server receives request
      ↓
  Sends IPC message 'tool-bridge-execute' to renderer
      ↓
  useToolBridge.js: onToolBridgeExecute() receives IPC
      ↓
  Looks up tool in tools.js registry
      ↓
  Calls tool.handler(params, appContext)
      ↓
  Sends IPC 'tool-bridge-result' back to main process
      ↓
  HTTP response to Python agent

  Key point: This path exists but the Python agent is never invoked by the main
  chat flow. The tool bridge server is running (started in main.js line 839),
  but nothing in the React code calls it.
