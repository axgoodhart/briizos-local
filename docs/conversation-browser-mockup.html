Quick tag edit. 􀅼 opens an inline combobox over the workspace vocabulary with usage counts. ↑/↓ move, Enter commits, Esc cancels, blur cancels. Creating a new tag is always the last option, never the first.

4 — When the model adds a tag Five gates run before the model is ever asked, so a greeting costs nothing.

  • Turn shape. Only after a completed assistant reply with no pending tool call, and never inside a sub-agent run.
  • Cap. At 5 tags the conversation is finished — it is never evaluated again. This is the main guard against endless curation.
  • Checkpoint. Evaluated only when the exchange count crosses 2, 4, 8, 16 or 32. A 40-turn conversation is checked at most five times, not forty.
  • Substance. Needs 2+ complete exchanges, 120+ characters of user text, 12+ distinct non-stopword words, and no small-talk match. “Hello” fails this and the checkpoint gate, so no model call is made and no tag is created.
  • Vocabulary. The existing workspace tags and their counts are handed to the model with an instruction to reuse before inventing — so the vocabulary converges instead of growing.
  • Append-only. The model can add at most 2 tags per check and can never rename or remove one. Anything you delete is remembered and never proposed again.
